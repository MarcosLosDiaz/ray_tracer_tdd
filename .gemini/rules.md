# Project Guidelines: Ray Tracer TDD

1. **No External Implementation Bias**:
   - Do NOT consult or infer code structure from existing third-party implementations of *The Ray Tracer Challenge*.
   - Only rely on the requirements, feature files, and instructions explicitly provided in this codebase or by the user.

2. **Strict Codebase & Specification Alignment**:
   - Always inspect local source files (`src/`, `tests/`) and Gherkin `.feature` files first to understand existing patterns and contracts before writing or suggesting new code.
   - Do not propose third-party idioms or external library structures unless explicitly requested.
